# Smart Entry — режим перевірки (read-only)

Цей пакет додає незалежний від LIVE-механізму моніторинг BingX-свічок для збережених TradingView-сигналів.

## Можливості
- Працює зі списком активних авторів і пропускає призупинених.
- Береться лише наявний AI-кеш, без нових запитів Gemini.
- Перевіряє 4+ закриті свічки відповідного TF; свічка, яка ще формується, не вважається сигналом.
- WAITING — ціна далеко від ENTRY; CONFIRMING — близько, але немає підтвердженої свічки; READY_REVIEW — технічне підтвердження знайдено, проте це **не дозвіл на ордер**; INVALID — очевидна нечинність; CHECK — недостатньо даних.
- Стан записується в `/data/tv_updates_monitor.sqlite`, таблиця `tv_smart_states`.

## Запуск без ордерів

```bash
python /app/tv_smart_scan.py --hours 16
```

Автоматичний запуск кожні 5 хв (мінімум 60 секунд):

```env
TV_SMART_ENTRY_ENABLED=1
TV_SMART_ENTRY_SECONDS=300
TV_SMART_ENTRY_LOOKBACK_HOURS=16
```

Цей режим **не відправляє ордерів** і не замінює чинний `tv_live_engine.py`. Якщо раніше були ввімкнуті `TRADING_MODE=live` і `TV_LIVE_EXECUTION=YES`, старий LIVE-конвеєр **залишається активним і може торгувати самостійно**. Щоб нова система працювала лише як монітор, не змінюйте ці перемикачі автоматично та врахуйте цей факт.

## Що треба до автоматичного SMART LIVE
- Підтверджувати живий стан ідеї автора, повноту історії свічок після публікації, невиконані ордери й безпечне скасування.
- Перевірити два біржові TP / захисні SL на тестовому або мінімальному контрольованому ордері, включно з частковими виконаннями.
- Переробити LIMIT-вхід: закрита свічка-підтвердження може з'явитися вже після торкання ENTRY, тому не можна автоматично ставити відкладений ордер на старому рівні.
