# Signalbot — TradingView LIVE execution blocker fixes

Патч **не змінює Railway Variables**, не активує новий спосіб виконання і не відкриває жодного ордера під час встановлення.

Виправлено:

1. `signal_from_evidence` більше не підставляє BTC для усіх USDT-пар; базова монета береться з нормалізованого символу TradingView.
2. `PlanError` (недостатній обсяг, невалідний SL, надто далека ціна) перетворюється на зрозумілий `SKIP` із причиною, а не на некерований виняток.
3. Якщо обидва `TV_SINGLE_ENTRY_PREVIEW=YES` та `TV_ONE_ENTRY_LIVE=YES`, виконання блокується з явною помилкою конфігурації замість прихованого переходу у preview.

Не змінено: вікові обмеження, мінімальні біржові розміри, відсутність незалежного підтвердження SL/TP, політики умовних ідей, запобігання повторним заявкам. Такі правила не можна безпечно видаляти заради більшої кількості угод.

## Встановлення

Розпакувати ZIP у корінь поточного `tg`, запустити `python -m unittest discover -s tests -q`, потім commit/push і деплой.

## Перевірка

`railway logs --lines 150`, `railway ssh`, `python /app/tv_live_audit.py`, `python /app/tv_one_entry_audit.py`, `python /app/tv_protection_audit.py`.

**LIVE-попередження:** звичайні unit-тести не доводять реальну роботу BingX SL/TP. Не залишати непідтверджений захист без нагляду. Не відправляти повторну заявку після мережевої невизначеності.
