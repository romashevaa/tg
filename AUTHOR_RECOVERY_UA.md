# Виправлення старих авторів TradingView і заблокованих профілів

Цей пакет **не відкриває BingX-угоди** і не змінює торговий режим.

## Що змінено

- Старі підписки з `tv_authors` переносяться до `tv_monitor_authors` автоматично, з `INSERT OR IGNORE`. Якщо раніше вручну вимкнули автора, його вимкнений статус зберігається.
- `/tvmonitors` після рестарту бачить усіх раніше доданих авторів; `/tvadd` і далі одразу включає їх.
- TradingView-профіль із прямим повідомленням `got suspended for bad behavior` або `suspended` і `House Rules` зберігається в SQLite як suspended на 12 годин.
- Протягом 12 годин не виконується профільний discovery, AI review чи історичний update цього автора. Через 12 годин бот перевіряє профіль повторно. Після підтвердженого розбану моніторинг відновлюється. Історія ідей та подій залишається.
- Недоступність мережі не вважається доказом блокування.
- У фоновому AI-воркері прибрано жорстке обмеження максимум 10 ідей за цикл; перемінна `TV_FULL_REVIEW_PER_CYCLE` використовується без цього обмеження.

## Встановлення

Розпакувати цей ZIP у корінь репозиторію `tg` із заміною файлів, потім:

```bash
python -m unittest discover -s tests -q
git add railway_start.py tv_author_settings.py tv_full_review.py tests/test_author_migration_suspension.py AUTHOR_RECOVERY_UA.md
git commit -m "Recover legacy TV authors and pause suspended profiles"
git push origin main
railway up
```

Після рестарту викликати `/tvmonitors`. Старі автори будуть активні, якщо їх раніше не було вимкнено в новому списку. Це **може призвести до нових запитів Gemini і витрат** за реальні нові публікації цих авторів.

## Що ще НЕ працює

- Gemini TradingView review не надсилає ордерів у BingX.
- TP1 80% і TP2 20% та контроль біржових заявок не реалізовані.
- Існуючий сигнал WLD є історичною ідеєю: перед входом потрібні поточна ціна, термін дії сигналу, перевірка плеча/маржі та стану заявок/позицій.
- Для одного TP можна розглядати TP1 як половину відстані від ENTRY до TP2, але це *новий, неавторський рівень*, який потрібно явно позначити в торговому плані та перевірити tick/step size біржі.
