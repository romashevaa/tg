# BingX: контрольоване розблокування live, НЕ фінальний автоматичний трейдер

Цей архів базується на `signalbot-tv-unlimited-authors.zip`. Залишає всі функції моніторингу авторів та наявний Telegram-конвеєр.

## Важливі обмеження

- **НЕ реалізовано обіцяне розбиття TP 80%/20%.** Live виконавець підтримує ОДИН TP за `config.toml` (`middle`). Для live використання поточного одного TP потрібне окреме явне підтвердження `ALLOW_SINGLE_TP_LIVE`.
- Автоматично знайдені TradingView ідеї **не створюють ордерів**. Тільки сигнали з налаштованого Telegram-каналу проходять торговий конвеєр.
- Live `MARKET` / `LIMIT` відповідь API про прийняття **не гарантує виконання**. Виконавець повертає `pending`, але немає повної автоматичної звірки після кожного ордера, захисту від повторних угод в усіх гонках і перевірки фактичних стоп/тейк-ордерів.
- Після перезапуску автоматичне відновлення стану повністю не реалізовано. Перевірити вручну `bingx_reconcile.py` і стан біржі.
- Поточні ліміти `risk_pct`, `max_margin_pct`, `max_open_positions` та `max_leverage` із конфігурації залишаються чинними.
- API-ключам не давати права виведення коштів. За можливості обмежити IP.

## Інсталяція

На Mac розпакувати в корінь `tg`, потім:

```bash
python -m unittest discover -s tests -v
git add signalbot railway_start.py tests LIVE_SWITCH_README_UA.md
git commit -m 'Add explicit BingX live opt-in (single TP only)'
git push origin main
railway up
```

Після деплою початковий `TRADING_MODE=shadow` залишається безпечним. Додавати ключі лише в Railway Variables.

## Свідоме увімкнення

ОБЕРЕЖНО: при встановленні трьох змінних бот зможе **автоматично відправляти реальні ордери** із Telegram-каналу, навіть коли ви не дивитеся в екран. ЦЕ НЕ РЕКОМЕНДУЄТЬСЯ доки автоматична звірка й 80/20 не реалізовані.

```env
TRADING_MODE=live
BINGX_LIVE_ACK=I_UNDERSTAND_REAL_ORDERS
ALLOW_SINGLE_TP_LIVE=I_ACCEPT_SINGLE_TP
```

Для повернення в тестовий режим: `TRADING_MODE=shadow` і перезапуск; це **не закриває** жодних уже відкритих реальних позицій. Їх потрібно контролювати на BingX.
