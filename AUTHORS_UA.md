# Багато TradingView авторів у Signalbot

Після одноразового деплою додавати нових авторів можна **через Telegram**, без редагування Python або повторного деплою.

- `/tvadd https://www.tradingview.com/u/username/` — зберегти й увімкнути автора.
- `/tvmonitors` — показати всіх авторів та стан їх моніторингу.
- `/tvunmonitor username` — призупинити сканування автора, не видаляючи історію.
- `/tvmonitor username` — поновити моніторинг.
- `/tvauthors` — попередня команда для перегляду збережених профілів.

Два попередні автори (`Altsignals`, `coinpediamarkets`) залишаються активними. Нові підхоплюються в наступному циклі (приблизно 60 с). Кожен новий автор отримує власну тиху початкову синхронізацію, щоб не надсилати всі старі публікації.

Моніторинг використовує TradingView public API; коли багато авторів, реальний інтервал залежить від кількості запитів, часу відповіді та лімітів сервісу. Кількість авторів у коді не обмежена, але гарантії перевірки кожного кожні 60 секунд за великого списку немає.

Періодичні перевірки старих ідей зберігаються окремо (типово 5 хв), завершені ідеї пропускаються. Відключення автора вимикає пошук **нових** публікацій; воно не видаляє вже знайдені ідеї та не зупиняє перевірку їхніх оновлень. Режим `shadow` не змінюється.

Встановлення: розпакувати архів у локальну папку `tg`, замінюючи файли, й виконати:

```bash
python -m unittest discover -s tests -v && \
git add signalbot/bot.py railway_start.py tv_author_settings.py tests/test_tv_author_settings.py AUTHORS_UA.md && \
git commit -m "Manage TradingView authors from Telegram" && \
git push origin main && \
railway up
```

Після успішного деплою в Telegram надіслати `/tvmonitors` і потім `/tvadd https://www.tradingview.com/u/username/`. Старі дані не видаляються.
