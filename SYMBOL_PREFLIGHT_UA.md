# TradingView / BingX: діагностика символів (LIVE)

У попередній версії `bingx_pair('BTCUSD')` уже повертав `BTC-USDT`; аналогічно `ETHUSD` → `ETH-USDT`, `WLDUSDT.P` → `WLD-USDT`. Тепер `tv_live_catchup.py` друкує результат публічної перевірки контракту та ціну для пропущених ідей. Це не створює ордерів і не змінює жодних ризикових умов.

Установлення: з папки локального проєкту `tg`: `unzip -o ~/Downloads/signalbot-bingx-symbol-diagnostics.zip -d .`, далі тести, git commit/push, railway up.

У LIVE **не запускай** catch-up лише для діагностики: він може відправляти реальні ордери. Для безпечного перегляду логу є `TRADING_MODE=shadow`, але це вимкне реальні входи доки змінну не повернеш. Коли запускатимеш у LIVE, контролюй ордери і захисні виходи безпосередньо на BingX.

Рядки на кшталт `symbol=BTCUSD pair=BTC-USDT contract=LISTED price=...` підтверджують наявність контракту. `UNVERIFIED` означає тимчасову помилку API, не доведену відсутність контракту. `TF=невідомий` далі блокує прострочений сигнал — це окрема перевірка.
