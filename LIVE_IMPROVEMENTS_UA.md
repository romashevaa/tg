# Signalbot: execution reliability patch

Ця збірка створена зі стану `tg 3.zip` + `signalbot-one-entry-live-experimental.zip` + `signalbot-execution-blocker-fixes.zip`.

## Виправлено
- API `_request` ніколи не робить автоматичну повторну спробу POST/DELETE/PUT після network timeout, щоб уникнути повторного ордера на іншому хості. GET може перемикати хост.
- One Entry: якщо TP2 20% не проходить біржовий мінімум, але повний вихід допустимий, preflight вибирає один TP1 на 100%. Жодного збільшення обсягу. SL при вході залишається обов'язковим.
- One Entry executor надсилає тільки один TP-вихід у SINGLE_TP_100 замість двох.
- Збережено окремий журнал виконання та підтвердження біржових станів.

## НЕ реалізовано у цій збірці
- Автоматичне переведення SL у BE після виконання TP1 та менеджер ордерів, який повністю відновлюється після рестарту.
- Надійний фоновий watcher частково виконаних LIMIT-входів для One Entry.
- Доказ, що attached SL зареєстрований біржею після входу.

Не вмикайте новий one-entry виконуючий шлях без перевірки ордерів на BingX. Наявність 91 успішних unit-тестів не доводить працездатності на реальній біржі.
