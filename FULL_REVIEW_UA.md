# Повний аналіз TradingView (текст + графік)

Цей пакет додає **ручний запуск** аналізу за останню годину з Gemini для доданих авторів. Аналіз не відкриває біржових позицій, навіть якщо Trading Mode = live. Не змінює інші файли моніторингу.

Після встановлення на Railway: `python /app/tv_full_review.py --hours 1 --max-ideas 6 --notify`.

- Перевіряє кожну нову ідею з графіком (коли завантажується) і текстом.
- Кешує аналіз за `idea_id` у `/data/tv_updates_monitor.sqlite`; повторний запуск не витрачає Gemini на ті самі ідеї. `--force` скидає цей захист лише для повторної перевірки та може коштувати грошей.
- Обмежує кількість платних AI-викликів за запуск (`--max-ideas`, стандартно 6).
- Відмовляється вгадувати нечитабельні ENTRY, SL і TP; це не ордер.
- Повністю автоматичного AI-аналізу кожної майбутньої ідеї **цей патч ще не робить**. Для нього слід інтегрувати чергу із фоновим воркером та бюджетом.
- Після деплою `TRADING_MODE` не змінюється. Ніяких реальних ордерів скрипт не надсилає.

## Автоматичний аналіз нових ідей
Railway Variables:
```
TV_FULL_REVIEW_ENABLED=1
TV_FULL_REVIEW_PER_CYCLE=2
TV_FULL_REVIEW_SECONDS=60
TV_FULL_REVIEW_LOOKBACK_HOURS=1
```
Бот переглядатиме нові ідеї з увімкнених авторів за останню годину за замовчуванням. Один аналіз на ідею зберігається в SQLite. За замовчуванням автоматичний AI вимкнений, щоб не спричинити витрати Gemini без явного ввімкнення. Аналіз може використовувати платні запити. Обмеження `PER_CYCLE=2` — тільки кількість нових AI-перевірок за один цикл, НЕ денний бюджет. Для великої кількості авторів можливі значні витрати.

`TV_FULL_REVIEW_ENABLED=0` повертає моніторинг лише з безкоштовною текстовою перевіркою. Жоден варіант не відкриває ордерів.
