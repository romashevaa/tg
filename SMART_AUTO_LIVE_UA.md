# Smart Entry → автоматична повторна оцінка → LIVE

Після деплою нові та вже кешовані TradingView-ідеї перевіряються окремим Smart Entry watcher. Автору не потрібно публікувати оновлення. Воркер враховує тільки ідеї за `TV_SMART_ENTRY_LOOKBACK_HOURS`, що присутні у останніх записах TradingView API та мають AI-кеш.

За замовчуванням це READ_ONLY. Для автоматичної спроби відправлення реальних ордерів додатково потрібно `TV_SMART_AUTO_EXECUTION=YES`, `TRADING_MODE=live`, `TV_LIVE_EXECUTION=YES`, `TV_SMART_ENTRY_LIVE_GATE=YES` і попередні ACK-змінні. Без них ордери не відправляються.

Сканувати раз на хвилину: `TV_SMART_ENTRY_SECONDS=60`. Самостійну діагностику без ордерів: `python /app/tv_smart_scan.py --hours 16`. Ручна live-спроба: `python /app/tv_smart_scan.py --hours 16 --execute-live` — **може створити реальні ордери**.

Вхід можливий лише за статусу READY_REVIEW на закритій свічці. Перед відправленням LIVE-виконавець заново перевіряє ринок, автора, вік ідеї, історію, SL/TP і стан ордерів. Атомарний запис в SQLite не дає двом воркерам відправити повторні ордери за одну ідею.

Обмеження: алгоритм не перевірений на реальному рахунку. Два ордери BingX можуть виконатися частково; не гарантовано, що прикріплені SL/TP працюють при частковому виконанні. Монітор **не скасовує** відкриті ордери після зміни сигналу. Уважно контролюйте перші виконання у застосунку BingX. Задля безпеки можна залишити `TV_SMART_AUTO_EXECUTION=NO` для перевірки станів.
