# One Entry LIVE — експериментальний режим

Поточний LIVE (`TV_LIVE_EXECUTION=YES`) залишений як є: два окремі входи 80/20. Нова схема **не вмикається автоматично після деплою**.

## Що реалізовано

- Опціонально одна `MARKET`-заявка в BingX Hedge Mode з **прикріпленим SL** і без TP на вході.
- Перед POST — атомарна реєстрація в SQLite за ID TradingView-ідеї, без повторних заявок при таймауті чи перезапуску.
- Після відповіді біржі — GET фактичного стану заявки та позиції. Тільки якщо входу відповідає `FILLED` з точною кількістю, бот надсилає дві `TAKE_PROFIT_MARKET` заявки на 80% і 20%.
- Перед кожною TP-заявкою — запис у SQLite; невизначені відповіді потребують ручної звірки, не ретраяться.
- `tv_one_entry_audit.py` — лише читання фактичних даних біржі та журналу.
- STOP/TP захист **не вважається верифікованим** за фактом прийняття API-запиту.
- BingX API transport: невизначений POST/DELETE ніколи не повторюється на резервному хості.

## Що НЕ готове і чому не рекомендується для unattended LIVE

1. `LIMIT`-входи свідомо не підтримуються в новому режимі: для часткових та відкладених виконань потрібен окремий постійний fill-watcher.
2. При повному `MARKET` fill два TP надсилаються після виконання входу. Тимчасово залишається лише прикріплений SL, і його фактична активність не доведена.
3. TP1/TP2 та SL можуть залишатися після закриття позиції; автоматичне безпечне скасування залишкових наказів **ще не реалізовано**.
4. 20% обсягу все одно може бути нижче мінімальних обсягів/номіналу біржі — такі сигнали пропускаються без збільшення ризику.
5. Звірка API `openOrders` не доводить активність прикріпленого SL. Немає інтеграційного тесту на реальному акаунті BingX.

## Перемикачі

За замовчуванням нова схема вимкнена. Вмикання можливе лише з `TV_ONE_ENTRY_LIVE=YES` і `TV_ONE_ENTRY_LIVE_ACK=I_ACCEPT_ONE_ENTRY_AND_TWO_TPS`. Якщо `TV_SINGLE_ENTRY_PREVIEW=YES`, preview виконується першим і **ніяких заявок новою схемою немає**. Поточні LIVE змінні та старий виконавець не змінено.

Щоб перевірити на Railway без заявок, залиште `TV_ONE_ENTRY_LIVE` невстановленою та використовуйте `TV_SINGLE_ENTRY_PREVIEW=YES`.

## Перевірка

```bash
python -m unittest discover -s tests -q
python /app/tv_one_entry_audit.py
python /app/tv_protection_audit.py
```

**Увага:** ця реалізація — проміжний крок до повного автоматичного біржового менеджера. Не встановлюйте `TV_ONE_ENTRY_LIVE=YES` до перевірки BingX `stopLoss` та conditional TP на демо/контрольованій позиції, і до реалізації звірки та скасування залишкових ордерів. Старий LIVE також не сертифікований як безпечний.
