# Smart Entry: 12h і контроль мінімального обсягу 80/20

Виправлення від 2026-10-11 для поточної бази `tg 2.zip`.

- 12h Smart Entry збирає лише **повністю закриті** UTC-вирівняні свічки з трьох 4h барів BingX. При нестачі/пропуску даних — `CHECK`, не LIVE.
- Якщо обсяг 20% менший за мінімальний розмір BingX, відповідь `SKIP` із поясненням замість необробленого `ValueError`. **Загальний ризик і кількість не збільшуються**.
- `CONDITIONAL` (breakout / retest) не торгується тільки за локальною свічкою біля ENTRY: `CHECK` до окремої перевірки умови автора.
- `ANALYSIS` та записи без повних торгових рівнів не дозволяють LIVE.

Важливо: поточний виконавець надсилає дві незалежні заявки з прикріпленими SL/TP, але факт їхньої активації BingX після виконання досі не доведено. Цей патч не вводить автоматичного скасування старих LIMIT-заявок чи відновлення невідомого TF. Перед LIVE переконайтеся в захисті позицій і звірте ордери через біржу.

Встановлення з каталогу `tg` на Mac:
```
unzip -o ~/Downloads/signalbot-smart-12h-80-20-fix.zip -d .
python -m unittest discover -s tests -q
git add -A && git commit -m 'Fix 12h Smart Entry and small 80/20 quantities' && git push origin main
railway up
```

В ZIP немає вкладеної `tg/` папки. Важливо: перед деплоєм `TV_LIVE_EXECUTION=NO` і `TV_SMART_AUTO_EXECUTION=NO`, оскільки LIVE-частина ще не повністю протестована на BingX.
