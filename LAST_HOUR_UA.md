# Моніторинг авторів TradingView та перевірка останньої години

## Що виправлено

- `/tvadd username` тепер не лише зберігає автора, а й **одразу вмикає** його моніторинг.
- Під час **першої** синхронізації щойно доданого автора з історії відбираються пости, опубліковані за останні **60 хвилин**, і створюються сповіщення. Старші ідеї зберігаються без масового спаму.
- Сканер `tv_last_hour.py` дозволяє одноразово перевірити недавні публікації усіх **увімкнених у Signalbot** авторів. Дублі повідомлень блокуються за idea ID.

## Установка (на Mac, в папці tg після розпакування)

```bash
python -m unittest discover -s tests -v && \
git add signalbot/bot.py tv_auto_alerts.py tv_last_hour.py tests/test_tv_last_hour.py LAST_HOUR_UA.md && \
git commit -m "Auto-monitor new TradingView authors and recover last-hour posts" && \
git push origin main && railway up
```

## Після деплою

У Telegram: `/tvmonitors` — переконатися, що потрібні автори позначені 🟢. Існуючого вимкненого автора можна ввімкнути `/tvmonitor username`.

З Mac: `railway ssh`, а потім **всередині Railway**:

```bash
python /app/tv_last_hour.py
```

Покаже пости **останніх 60 хвилин** за доступною датою створення в TradingView API — жодних повідомлень чи ордерів.

```bash
python /app/tv_last_hour.py --notify
```

Додатково надішле знайдені публікації в Telegram, якщо ключ `idea:<id>` ще не відправлявся. Без Gemini та без реальної торгівлі.

**Увага:** "автори, на яких я підписаний" = лише додані/увімкнені в Signalbot `/tvmonitors`. Список особистих TradingView Followings не доступний без авторизованого доступу до акаунта. Для інших профілів — `/tvadd username`.

**Додатково:** перевірка знаходить **публікації**, але не підтверджує повноцінні торгові умови / вхід / ризик / SL / TP, не аналізує графік моделлю і НЕ передає TradingView-ідеї у виконання BingX. Режим BingX не змінюється.

API наразі повертає першу сторінку до 50 ідей на автора; якщо публікацій більше 50 за годину, потрібна пагінація для повного покриття.
